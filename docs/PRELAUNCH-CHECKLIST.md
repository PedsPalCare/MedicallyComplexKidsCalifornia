# Prelaunch checklist

## P0 content and governance

- [ ] Final name, trademark, domain, entity, governance, and public contact approved
- [ ] No fabricated resource, story, partner, position, statistic, contact, or testimonial
- [ ] Every core claim has primary source, effective date when relevant, named owner/reviewer, last and next review
- [ ] All 58 counties and split ZIP/catchment routes verified against official sources
- [ ] Medi-Cal, CCS/WCM, HCBA/WPCS, Regional Center, IHSS, school, private insurance, and transition pathways reviewed by qualified California SMEs
- [ ] Every deadline and continued-service statement reviewed against current governing authority
- [ ] Former Partners for Children waiver not presented as enrolling
- [ ] Editorial, corrections, accessibility, privacy, archive, disclaimer, and consent policies approved

## P0 Spanish

- [ ] Launch-critical journeys and high-stakes guidance translated and reviewed by qualified humans
- [ ] California terminology glossary approved
- [ ] Spanish revision matches approved English revision
- [ ] Reviewer identities/roles and review dates recorded
- [ ] Spanish navigation, validation, print, share, sources, and `lang`/`hreflang` manually tested
- [ ] No machine-only high-stakes translation is public

## Functionality

- [ ] Every link, button, filter, form, and control has a real action
- [ ] Each home need reaches a credible next step within three activations
- [ ] All eight denial systems and “unsure” work
- [ ] Finder filter/reset/no-results/print/save/share work after hard reload
- [ ] Advocacy always previews and never sends automatically
- [ ] Story builder defaults to no retention and clears completely
- [ ] Active and archived campaigns cannot be confused
- [ ] Search, 404, correction route, sitemap, canonical, and external-link behavior work

## Accessibility

- [ ] Automated suite passes with zero serious/critical findings
- [ ] Independent manual WCAG 2.2 AA audit passes
- [ ] VoiceOver, NVDA, TalkBack, keyboard, 400% zoom, forced-colors, and reduced-motion tests pass
- [ ] Disabled English- and Spanish-speaking family participants complete P0 tasks
- [ ] Downloads have accessible HTML equivalents
- [ ] Public accessibility contact and response process approved

## Privacy and security

- [ ] Data inventory, retention, deletion, vendor, and incident owner approved
- [ ] Network/storage inspection proves local-only tools remain local
- [ ] No ads, session replay, or unapproved analytics
- [ ] Production forms have server validation, rate limits, spam controls, encryption, least privilege, and deletion
- [ ] TLS and security headers verified on production
- [ ] Dependency, secret, SAST, and DAST scans pass
- [ ] Drafts/private submissions cannot appear in public CMS API, search, sitemap, feeds, or preview
- [ ] Backup restoration and incident rollback rehearsed
- [ ] California privacy and minors’ consent reviewed by counsel

## Performance and operations

- [ ] Mobile performance budgets pass under throttling
- [ ] Required browser/device matrix passes
- [ ] Broken-link, content-review, translation-mismatch, and expiration jobs run reliably
- [ ] GitHub Pages source is set to Actions and deployment verified
- [ ] Preview environments are not indexed
- [ ] CMS export, backup, restore, and vendor-exit plan tested
- [ ] Named launch decision-maker and rollback threshold documented
